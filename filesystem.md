## Who Writes What

| File | Edited By | When |
|---|---|---|
| `config.toml` | Human / configurator | Setup or tuning |
| `.env` | Human / configurator | Setup |
| `action.toml` / `interface.toml` | Human / configurator | Adding/configuring plugins |
| `persona.toml` | Human / configurator | Per-persona plugin selection |
| `action.py` / `interface.py` | Human (developer) | Building new plugins |
| `core/*.py` | Human (developer) | Rarely — core is stable |
| `character.json`, `style.md`, `values.md`, `lorebook.json` | Human | Soul crafting |
| `projects.md` | **AI** | Autonomous writing action |
| `state.json` | **Python** (engine) | Every wake cycle |
| `chroma_db/` | **Python** (memory manager) | Every memory operation |
| `kid.log` | **Python** (logging) | Continuous |

## Plugin Contracts

### Action Plugin
```python
# actions/<name>/action.py

MANIFEST = {
    "name":        "my_action",      # machine ID — must be unique
    "description": "What it does",   # shown in configurator
    "weight":      0.20,             # default probability share
}

async def run(ctx: PluginContext) -> str:
    # ctx.llm      — LLMBridge (generate, embed, summarise)
    # ctx.memory   — MemoryManager (retrieve, add)
    # ctx.state    — dict (mutable; engine saves after run)
    # ctx.send     — async callable to send via any interface
    # ctx.dry_run  — bool; skip external calls if True
    # ctx.persona_files — soul file contents
    # ctx.extra    — dict; toml_config injected here by loader
    return "one-sentence summary of what was done"
```

### Interface Plugin
```python
# interfaces/<name>/interface.py

MANIFEST = {
    "name":        "my_interface",
    "description": "What it connects to",
    "type":        "bidirectional",  # or "sensor" or "output-only"
    "requires":    ["MY_API_TOKEN"], # env var names
}

async def start(inbox_queue: deque) -> None: ...
async def stop() -> None: ...
async def send(target, text: str) -> None: ...  # omit for sensors
async def poll(inbox_queue: deque) -> None: ...  # optional; called each wake cycle
```

## Quick Start

```bash
# 1. System packages
sudo apt install -y python3 python3-pip python3-venv git tmux curl

# 2. Ollama
curl -fsSL https://ollama.com/install.sh | sh
ollama pull gemma2:27b && ollama pull nomic-embed-text

# 3. Python env
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# 4. Interactive setup (generates .env and config.toml)
python configurator.py

# 5. Run
tmux new-session -s kid
python kid.py --persona william

# Detach: Ctrl+B D
# Re-attach: tmux attach -t kid
# One-shot test: python kid.py --persona william --once --dry-run
```

## Adding a New Action (Example: Daily Haiku)

```bash
mkdir actions/daily_haiku
```

```toml
# actions/daily_haiku/action.toml
[action]
enabled     = true
name        = "daily_haiku"
description = "Write a haiku about something the character noticed today"
weight      = 0.10
```

```python
# actions/daily_haiku/action.py
from core.context import PluginContext

MANIFEST = {
    "name": "daily_haiku",
    "description": "Write a daily haiku",
    "weight": 0.10,
}

async def run(ctx: PluginContext) -> str:
    haiku = ctx.llm.generate(
        prompt="Write a haiku about something you noticed today.",
        system=ctx.get_soul("character"),
    )
    return f"Wrote a haiku: {haiku}"
```

Then add `"daily_haiku"` to the persona's `persona.toml` → `[actions] enabled` list.
**No other files need to change.**
